# d3-test

Демо-проект динамичной схемы владения на **D3.js**.

## Запуск

Достаточно открыть `index.html` в браузере.

## Что реализовано

- Ортогональные связи (горизонтально/вертикально).
- Раскладка нод слева направо по `level` (больше `level` -> правее).
- Маршрутизация связей в вынесенных каналах, чтобы связи не проходили через ноды.
- Для каждого родителя выделена уникальная координата `x` (lane), по которой связи этого родителя меняют `y`.
- Все исходящие связи одного родителя имеют одинаковый цвет.
- Стрелка на конце каждого линка.
- Поддержка меток (`tags`) и кастомных стилей нод по меткам.

## Формат входных данных

1 запись описывает 1 связь:

- `id_владельца` / `owner_id`
- `id_организации` / `organization_id`
- `level_организации` / `organization_level`
- `доля_владения` / `share`
- дополнительные флаги (`flags`, `характеристики`)
- метки ноды (`tags`, `метки`) — для стилизации

Пример:

```json
[
  {
    "id_владельца": "PARENT_A",
    "id_организации": "ORG_1",
    "level_организации": 1,
    "доля_владения": "65%",
    "tags": ["critical"]
  },
  {
    "id_владельца": "ORG_1",
    "id_организации": "ORG_3",
    "level_организации": 2,
    "доля_владения": "51%",
    "flags": { "foreign": true }
  }
]
```

## Стили меток

JSON в блоке "Стили меток нод":

```json
{
  "critical": { "fill": "#ffe4e8", "stroke": "#cc2f47", "strokeWidth": 2 },
  "foreign": { "fill": "#e8f5ff", "stroke": "#247ea6", "strokeWidth": 2 }
}
```
